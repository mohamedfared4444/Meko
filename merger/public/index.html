MP4 عالي الجودة (H.264 + AAC) حتى 1080p — مجانًا وبدون تسجيل
اسحب ملفات الفيديو هنا أو اختر ملفات من جهازك
mp4 / mov / webm / mkv / avi / m4v / mpg / 3gp — حتى 200MB لكل ملف
    توثيق API للمطورين
    MethodEndpointالوظيفة
    POST/api/jobsإنشاء مهمة دمج
    POST/api/upload?job=&seq=&chunk=رفع أجزاء الملفات (ثنائي ≤4MB)
    POST/api/jobs/<id>/processتنفيذ الدمج كاملًا
    GET/api/jobs/<id>الحالة + التقدم + الرابط
    GET/api/jobs/<id>/videoبث الناتج (يدعم Range)
    DELETE/api/jobs/<id>حذف فوري شامل
    GET/api/configالحدود العامة
    GET/api/cronحذف المهام المنتهية

    الأخطاء بصيغة {"error":"..."} — CORS مفتوح — بلا تسجيل دخول.

    curl -X POST __BASE__/api/jobs -H "Content-Type: application/json" -d '{"videos":["https://site.com/a.mp4","https://site.com/b.mp4"]}'
# ثم:
curl -X POST __BASE__/api/jobs/__JOB__/process
